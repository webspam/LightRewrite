## Standard character ranges

| Range (dec) | Content | Block                            |
| ----------- | ------- | -------------------------------- |
| 48–57       | `0`–`9` | ASCII digits                     |
| 65–90       | `A`–`Z` | ASCII                            |
| 97–122      | `a`–`z` | ASCII                            |
| 192–255     | `À`–`ÿ` | Latin-1 letters                  |
| 256–382     | `Ā`–`ž` | Latin Extended-A (fully covered) |
